# 🤖 Jarvis Assistant - Локальный голосовой ассистент

Умный голосовой ассистент с возможностями управления приложениями, автоматизации и интеграции с LLM.

## ✨ Основные возможности

### 🗣️ Голосовое управление
- Активация по слову-триггеру "Джарвис"
- Распознавание русской речи
- Синтез речи с настраиваемыми голосами

### 🖥️ Управление приложениями
- **Открытие программ**: "Открой блокнот", "Запусти браузер"
- **Закрытие приложений**: "Закрой калькулятор", "Завершить Chrome"
- **Ввод текста**: "Напиши привет мир", "Введи мой email"
- **Управление клавишами**: "Сохрани файл", "Скопируй", "Вставь"
- **Переключение окон**: "Переключись на Telegram"

### 🌐 Веб-команды и интернет
- **Популярные сайты**: "Открой YouTube", "Перейди на Google"
- **Поиск**: "Найди рецепт борща", "Поищи на ютубе уроки"
- **Специальные**: "Переведи hello world", "Погода в Москве"
- **Новости**: "Новости технологий", "Что нового"

### 📊 Google Sheets и отчеты
- **Задачи**: "Добавь задачу", "Покажи задачи", "Задача выполнена"
- **Учет времени**: "Начинаю работу над проектом", "Заканчиваю работу"
- **Отчеты**: "Отчет за день", "Недельный отчет"
- **Заметки**: "Добавь заметку встреча в 15:00"

### 🧠 ИИ интеграция
- Работа с локальными LLM через Ollama
- Контекстные разговоры с памятью
- Выполнение системных команд

### 📊 Мониторинг и управление
- Отслеживание производительности системы
- Веб-панель для удаленного мониторинга
- Управление настройками через конфигурационные файлы

## 🚀 Быстрый старт

### 1. Первоначальная настройка
```bash
python setup_jarvis.py
```

### 2. Проверка системы
```bash
python check_dependencies.py
```

### 3. Запуск ассистента
```bash
python start_jarvis.py
```

Или напрямую:
```bash
python main.py
```

### 4. Текстовый режим (для отладки)
```bash
python main.py --text
```

### Альтернативная установка
Если автоматическая настройка не работает:
```bash
pip install -r requirements.txt
cp .env.example .env
# Отредактируйте .env под свои нужды
```

## ⌨️ Клавиши управления

В консоли доступны быстрые команды:
- `q` + Enter - Выход
- `c` + Enter - Очистить историю
- `s` + Enter - Статус системы
- `p` + Enter - Производительность
- `m` + Enter - Вкл/выкл звук
- `r` + Enter - Перезапуск компонентов
- `v+/v-` + Enter - Управление громкостью
- `a` + Enter - Доступные приложения
- `l` + Enter - Запущенные программы
- `w` + Enter - Справка по веб-командам
- `g` + Enter - Справка по Google Sheets
- `t` + Enter - Текущая рабочая сессия
- `h` + Enter - Справка

## 🔧 Настройка

### Ollama
1. Установите Ollama: https://ollama.ai
2. Загрузите модель: `ollama pull llama2`
3. Запустите сервер: `ollama serve`

### Google Sheets (опционально)
1. Создайте проект в Google Cloud Console
2. Включите Google Sheets API
3. Скачайте credentials.json в папку `credentials/`

### Микрофон
1. Подключите микрофон
2. Настройте как устройство по умолчанию
3. Проверьте уровень записи

1. Архитектура
Локальный Джарвис — это модульный голосовой ассистент с следующей архитектурой:

Ядро системы (main.py) — orchestrator, управляющий потоком данных между модулями
STT модуль (stt.py) — использует Whisper для распознавания речи через микрофон
LLM модуль (llm_client.py) — взаимодействует с Ollama API для обработки запросов
TTS модуль (tts.py) — синтезирует речь через pyttsx3 (кроссплатформенный)
Google Sheets модуль (sheets_client.py) — CRUD операции с таблицами
System Tools модуль (system_tools.py) — выполнение системных команд
Utils модуль (utils.py) — вспомогательные функции и логирование

Поток данных: Микрофон → STT → LLM → Обработка команд → TTS → Динамики
2. Roadmap разработки
Этап 1: MVP (1-2 недели)

Базовое распознавание речи (Whisper)
Подключение к Ollama API
Простой TTS через pyttsx3
Обработка базовых команд
Логирование

Этап 2: Интеграции (2-3 недели)

Google Sheets API интеграция
Системные команды (открытие приложений, управление файлами)
Wake word detection ("Джарвис")
Улучшенная обработка ошибок

Этап 3: Расширенные функции (3-4 недели)

Контекстная память разговоров
Планировщик задач
Интеграция с календарем
Настраиваемые голоса TTS

Этап 4: UI и оптимизация (4+ недели)

Web UI на FastAPI
Оптимизация производительности
Плагинная система
Docker контейнеризация

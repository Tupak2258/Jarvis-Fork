# 🔒 Руководство по закрытию приложений

## ✅ Исправлено! Закрытие приложений теперь работает корректно

### 🎯 Поддерживаемые команды закрытия:

#### Основные команды:
- "Закрой блокнот"
- "Выключи калькулятор"
- "Завершить браузер"
- "Остановить Telegram"
- "Закрыть Word"

#### Дополнительные варианты:

### 🔧 Как это работает:

1. **Умное распознавание**: Система автоматически находит правильные процессы для каждого приложения
2. **Мягкое закрытие**: Сначала пытается закрыть приложение корректно
3. **Принудительное закрытие**: Если мягкое закрытие не работает, принудительно завершает процесс
4. **Множественные процессы**: Закрывает все связанные процессы приложения

### 🧪 Тестирование:

Для тестирования команд используйте:
```bash
python test_app_close.py --test
```

Для просмотра запущенных процессов:
```bash
python test_app_close.py --list
```

### ⚠️ Важные замечания:

1. **Безопасность**: Системные процессы защищены от случайного закрытия
2. **Права доступа**: Некоторые процессы могут требовать прав администратора
3. **Множественные окна**: Закрывает все окна приложения одновременно
4. **Логирование**: Все операции записываются в лог для отладки

### 🔍 Отладка:

Если приложение не закрывается:
1. Проверьте точное название в диспетчере задач
2. Убедитесь, что процесс не защищен системой
3. Попробуйте разные варианты команды
4. Проверьте логи в папке `logs/`

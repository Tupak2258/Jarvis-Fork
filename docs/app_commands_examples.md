# 🤖 Примеры команд управления приложениями для Джарвиса

## 📂 Открытие и закрытие приложений

### Открытие:
- "Открой блокнот"
- "Запусти калькулятор" 
- "Включи браузер"
- "Открыть Word"
- "Запустить Telegram"

### Закрытие:
- "Закрой блокнот"
- "Выключи калькулятор"
- "Завершить браузер"
- "Остановить музыку"
- "Закрыть все окна Chrome"

## ⌨️ Ввод текста и управление

### Ввод текста:
- "Напиши привет мир"
- "Введи мой адрес электронной почты"
- "Печатай сообщение для друга"
- "Набери номер телефона"
- "Вставь текст добро пожаловать"

### Управление клавишами:
- "Сохрани файл" (Ctrl+S)
- "Скопируй" (Ctrl+C)
- "Вставь" (Ctrl+V)
- "Выдели всё" (Ctrl+A)
- "Отмени" (Ctrl+Z)
- "Новый файл" (Ctrl+N)

### Специальные клавиши:
- "Нажми энтер"
- "Нажми пробел"
- "Нажми таб"
- "Нажми эскейп"
- "Нажми бэкспейс"

## 🔄 Переключение между окнами

- "Переключись на блокнот"
- "Перейди к браузеру"
- "Активируй Telegram"
- "Фокус на Word"
- "Переключись на калькулятор"

## 📋 Информационные команды

## ⚠️ Важные замечания

1. **Точность названий**: Джарвис понимает как русские, так и английские названия программ
2. **Активное окно**: Команды ввода текста работают с активным окном
3. **Безопасность**: Некоторые системные процессы могут быть защищены от закрытия
4. **Задержки**: После команд переключения окон есть небольшая пауза для корректной работы

## 🎮 Клавиатурные команды в консоли

- `a` + Enter - Показать доступные приложения
- `l` + Enter - Список запущенных программ
- `h` + Enter - Справка по всем командам

# 📱 Интеграция с Telegram для Jarvis

## 🎯 Возможности

Jarvis теперь может работать с Telegram Desktop, используя компьютерное зрение и модель QwenVL для анализа чатов и извлечения данных.

### ✨ Основные функции:

1. **🚀 Управление Telegram**
   - Открытие и активация Telegram Desktop
   - Поиск и открытие чатов по имени
   - Навигация по интерфейсу

2. **📸 Анализ с помощью QwenVL**
   - Создание скриншотов чатов
   - Распознавание и анализ текста
   - Понимание контекста разговоров
   - Анализ эмоциональной окраски

3. **📊 Извлечение данных**
   - Контакты (имена, телефоны, email)
   - Даты и временные периоды
   - Числовые данные (цены, количества)
   - Задачи и поручения
   - Ссылки и упоминания

4. **💾 Интеграция с Google Sheets**
   - Автоматическое сохранение извлеченных данных
   - Структурированное хранение информации
   - Категоризация по типам данных

## 🔧 Настройка

### 1. Установка зависимостей:
```bash
pip install pygetwindow opencv-python pytesseract Pillow
```

### 2. Настройка Tesseract OCR:
- Скачайте Tesseract: https://github.com/UB-Mannheim/tesseract/wiki
- Добавьте в PATH или укажите путь в коде

### 3. Проверка модели QwenVL:
```bash
ollama pull qwen2.5vl:7b
ollama list  # Проверить установленные модели
```

### 4. Запуск Telegram Desktop:
- Установите Telegram Desktop (не веб-версию)
- Войдите в аккаунт
- Оставьте приложение запущенным

## ⚠️ Ограничения и замечания

### Технические ограничения:
- Работает только с Telegram Desktop
- Требует активного окна для скриншотов
- Зависит от качества OCR распознавания
- Модель QwenVL должна быть загружена в Ollama

### Безопасность:
- Скриншоты сохраняются локально
- Данные передаются только в локальную модель
- Не требует API токенов Telegram
- Работает через GUI автоматизацию

### Производительность:
- Анализ изображений может занимать 10-30 секунд
- Зависит от размера и сложности скриншота
- Требует достаточно ОЗУ для модели QwenVL

## 🔍 Отладка

### Проблемы с Telegram:
```bash
# Проверить запущен ли Telegram
python -c "from modules.telegram_manager import TelegramManager; tm = TelegramManager(); print('Telegram запущен:', tm.is_telegram_running())"
```

### Проблемы с QwenVL:
```bash
# Проверить модель
ollama list | grep qwen2.5vl
```

### Проблемы со скриншотами:
- Убедитесь, что Telegram в фокусе
- Проверьте разрешения на создание скриншотов
- Посмотрите папку `data/telegram_screenshots/`

## 📊 Структура данных в Google Sheets

Извлеченные данные сохраняются в таблицу со следующей структурой:

### Лист "Tasks":
- **[Telegram contacts]** - найденные контакты
- **[Telegram dates]** - важные даты
- **[Telegram numbers]** - числовые данные
- **[Telegram tasks]** - задачи и поручения
- **[Анализ Telegram]** - результаты анализа

### Метаданные:
- Время извлечения
- Путь к скриншоту
- Тип анализа
- Контекст данных

## 🔧 Клавиатурные команды

В консоли доступны быстрые команды:
- `w` + Enter - Справка по веб-командам
- `g` + Enter - Справка по Google Sheets
- `t` + Enter - Информация о текущей рабочей сессии

## ⚠️ Важные замечания

1. **Google Sheets**: Требует настройки credentials.json
2. **Интернет**: Необходимо подключение к интернету
3. **Браузер**: Команды открывают сайты в браузере по умолчанию
4. **Отчеты**: Автоматически создается лист "Work_Reports"
5. **Время**: Учет времени ведется в минутах
6. **Поиск**: Использует Google для неизвестных запросов
